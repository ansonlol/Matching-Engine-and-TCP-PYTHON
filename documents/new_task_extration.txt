Phase A — Engine process alone

Add matching_engine_server.py
Copy/adapt matcher’s _handle_add/cancel/modify to run after read_message
Run: python -m gateway.matching_engine_server 10000
Test with a tiny script that connects as a fake gateway and sends one AddOrder

Phase B — Gateway talks to engine

Add engine_client.py
In tcp_server.py: on startup connect to 127.0.0.1:10000
Client message → engine_client.send → read engine replies → send to client
Remove in-process Matcher + OrderService from gateway process
